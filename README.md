# Sri Murari Dachepalli

Data Engineer and Data Analyst building pipelines that reconcile — ingestion, modeling, and data quality on modern cloud stacks.

Arlington, VA · MS CS, George Washington University — May 2026

## About

MS in Computer Science from George Washington University, May 2026. Before that, a Data Analyst at Tiger Analytics for ten months, building ETL pipelines and tuning pricing models on Azure Databricks. My project work runs on AWS, Snowflake, and dbt, with an emphasis on reconciliation and tested, documented models.

## Selected Work

![EDGAR Pipeline](https://img.shields.io/badge/Project-EDGAR_Pipeline-0e7a5f?style=flat-square)

**[EDGAR Pipeline](https://github.com/Srimurari14/edgar-insider-pipeline)**
A daily SEC Form 4 pipeline: ingestion on AWS, dbt on Athena — 6 models and 19 tests — over 80,000+ rows of insider transactions, with an AI / LLM tool-calling layer on top, and a [live dashboard](https://d1mpwilwebyjo4.cloudfront.net/).
AWS · dbt · Athena · AI / LLM · Python

![Weather](https://img.shields.io/badge/Project-Weather-F2B33D?style=flat-square)

**[Production Weather Pipeline](https://github.com/Srimurari14/production-weather-pipeline)**
The first pipeline I built after my masters, and still one I'm proud of. OpenWeather data landed in Snowflake and modeled as a dbt star schema. Run manually; the scheduled GitHub Actions workflow is currently disabled.
Snowflake · dbt · Python

![GenieVision](https://img.shields.io/badge/Project-GenieVision-E4572E?style=flat-square)

**[GenieVision — Text-to-Image Model](https://github.com/Srimurari14/GenieVision)**
A class project I loved building: a text-to-image generation model based on latent diffusion, trained on COCO data.
Latent Diffusion · PyTorch · COCO

Also: **[Retail Sales Analytics](https://github.com/Srimurari14/retail-sales-analytics)** — SQL analytics and reconciliation across 100,000+ e-commerce orders from 9 sources, with a [Tableau dashboard](https://public.tableau.com/app/profile/sri.murari.dachepalli/viz/E-CommerceSalesDeliveryPerformanceDashboard/Dashboard1). SQL · Tableau
